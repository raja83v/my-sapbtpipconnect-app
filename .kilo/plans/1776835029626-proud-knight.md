# CPI Connect — Comprehensive App Analysis & Improvement Plan

## Executive Summary

CPI Connect is a sophisticated SAP CPI management platform built on **Next.js 16 + App Router**, **Supabase Auth**, **Drizzle ORM (PostgreSQL)**, **Vercel AI SDK**, and **shadcn/ui**. The codebase spans ~35,000+ lines across ~200 files, featuring multi-tenant SAP CPI integration, a multi-agent AI pipeline for iFlow generation, an MCP server, and both cloud and self-hosted deployment modes.

After a thorough analysis of every component, server action, API route, library, and configuration file, the findings below are organized by severity and domain.

---

## Part 1: Security Issues (Critical)

### 1.1 Debug Encryption Key Endpoint Leaks Key Material

- **File:** `app/api/debug/encryption-key/route.ts`
- **Issue:** Publicly accessible endpoint (no auth check) that reveals 16 of 32 encryption key characters and whether an env key is set. Drastically reduces brute-force search space.
- **Fix:** Delete this file entirely. If debug info is needed, gate behind `requireAdmin()` AND `NODE_ENV !== 'production'`.

### 1.2 MCP Destructive Action Confirmation Bypassed

- **File:** `app/api/mcp/tools/route.ts:131`
- **Issue:** Comment says "For now, accept any confirmation token" — destructive SAP CPI operations (deploy, undeploy, restart) execute without real token validation despite `mcp-server/src/utils/confirmation.ts` having a proper token system.
- **Fix:** Wire up the `ConfirmationManager` from the MCP server to validate tokens before executing destructive actions.

### 1.3 Corporate TLS Fix Can Disable All TLS Verification

- **File:** `lib/corporate-tls.ts`
- **Issue:** Sets `NODE_TLS_REJECT_UNAUTHORIZED=0` globally when `CORPORATE_NETWORK=true`. If accidentally enabled in production, all HTTPS (Supabase, SAP, AI providers) becomes vulnerable to MITM attacks.
- **Fix:** Add production guard: `if (process.env.NODE_ENV === 'production') { console.warn(...); return; }`.

### 1.4 Credential Decryption Inconsistency

- **Files:** `app/api/mcp/tools/route.ts:286-290`, `app/api/ai/chat/route.ts`
- **Issue:** Some code paths pass encrypted credential blobs directly to the SAP CPI client without decrypting first. Comments say "Client will decrypt" but the client doesn't always do so.
- **Fix:** Centralize a `getDecryptedTenantCredentials(tenant)` helper and use it everywhere.

### 1.5 No Rate Limiting on Auth Endpoints

- **Files:** `app/api/auth/sign-in/route.ts`, `app/api/auth/sign-up/route.ts`
- **Issue:** No application-level rate limiting against credential stuffing or signup abuse.
- **Fix:** Add rate limiting middleware or use the MCP server's `RateLimiter` pattern.

### 1.6 APIM Diagnostics Endpoint Missing Auth Guard

- **File:** `app/api/apim-diagnostics/route.ts`
- **Issue:** Route handler doesn't verify authentication before processing.
- **Fix:** Add `requireAuth()` at the top of the handler.

### 1.7 `.env` File May Be Committed

- **Issue:** Both `.env` and `.env.example` exist. Verify `.env` is in `.gitignore`.
- **Fix:** Add `.env` to `.gitignore` if not already present.

## Part 2: Data Integrity & Reliability Issues (High)

### 2.1 Non-Transactional Account Deletion

- **File:** `app/actions/user-settings.ts` — `deleteUserAccount()`
- **Issue:** Performs 9 sequential DELETE operations across 8+ tables without a DB transaction. Partial failure leaves orphaned data.
- **Fix:** Wrap in `db.transaction(async (tx) => { ... })`.

### 2.2 Missing Foreign Key Constraints in Schema

- **File:** `lib/db/schema.ts`
- **Issue:** Foreign key columns use plain `text()` without `.references()`. No database-level referential integrity — orphaned rows can accumulate.
- **Fix:** Add `.references(() => targetTable.id, { onDelete: 'cascade' })` to all FK columns.

### 2.3 Pipeline JSON Stored as Text Columns

- **File:** `lib/db/schema.ts` — `iFlowPipelines` table
- **Issue:** Serialized JSON objects stored in `text` columns instead of `jsonb`, preventing database-level querying.
- **Fix:** Migrate to `jsonb()` columns.

### 2.4 Token Cache Has No Size Limit

- **File:** `lib/token-cache.ts`
- **Issue:** In-memory `Map` grows unbounded with no max-size or periodic cleanup.
- **Fix:** Add max-entries limit and periodic expiry sweep.

### 2.5 AI Chat Background Task Not Abortable

- **File:** `app/api/ai/chat/route.ts:512`
- **Issue:** Async IIFE runs tool loop after Response is returned. If client disconnects, AI/tool calls continue wasting resources.
- **Fix:** Pass `AbortController.signal` to the streaming loop and listen for stream close.

### 2.6 SAP CPI Client Has No Retry Logic

- **File:** `lib/sap-cpi/client.ts` (1,327 lines)
- **Issue:** Raw `fetch()` with no retries. SAP CPI APIs have transient failures, 429 rate limits, and token refresh issues.
- **Fix:** Add exponential backoff retry wrapper for transient errors (5xx, 429, network errors).

### 2.7 Cron Secret Comparison Not Timing-Safe

- **Files:** `app/api/cron/sync-all-tenants/route.ts`, `app/api/cron/sync-executions/route.ts`
- **Issue:** Uses `!==` for secret comparison, which is theoretically vulnerable to timing attacks.
- **Fix:** Use `crypto.timingSafeEqual()` for bearer token comparison.

## Part 4: Code Quality & Architecture Issues

### 4.1 Two Competing `getCurrentUser()` Implementations

- **Files:** `app/actions/user.ts` vs `lib/auth-helpers.ts`
- **Issue:** Different behavior (lazy user creation, Supabase ID backfill, caching). Some actions import one, some the other.
- **Fix:** Consolidate into a single canonical implementation in `lib/auth-helpers.ts`.

### 4.2 Legacy Workspace Action Files

- **Files:** `workspace-members.ts`, `workspace-settings.ts`, `workspace-invitations.ts`
- **Issue:** Wrapper files around tenant operations, duplicating auth logic. Dead code that adds confusion.
- **Fix:** Deprecate with `console.warn` or remove, updating any remaining callers.

### 4.3 Excessive `any` Type Usage

- **Files:** `app/api/mcp/tools/route.ts`, `app/api/ai/chat/route.ts`, `lib/sap-cpi/bpmn2-generator.ts`
- **Issue:** ~50+ `as any` casts suppress TypeScript's safety guarantees.
- **Fix:** Define proper interfaces and type guards. Prioritize the MCP tools route and AI chat route.

### 4.4 BPMN2 Generator Too Large (3,401 lines)

- **File:** `lib/sap-cpi/bpmn2-generator.ts`
- **Issue:** Single file handles 50+ adapter types, layout, routing, scripting, mapping generation.
- **Fix:** Decompose into modules: `adapters/`, `layout.ts`, `process-builder.ts`, `security.ts`.

### 4.5 Admin Impersonation Stub Exposed in UI

- **File:** `app/actions/admin/impersonate.ts`
- **Issue:** Has `TODO: Implement JWT-based impersonation` but the UI exposes the feature.
- **Fix:** Either implement or hide the UI entry point behind a feature flag.

### 4.6 Billing Stubs

- **Files:** `app/actions/billing.ts`, `app/actions/admin/billing.ts`
- **Issue:** Empty stubs (19 and 92 lines) left after billing was removed.
- **Fix:** Remove dead code or add clear `// TODO` comments with feature flag.

### 4.7 Zero Test Coverage

- **Issue:** No test files found (`*.test.*`, `*.spec.*`).
- **Fix:** Add tests for critical paths: encryption, BPMN2 generator/validator, JSON cleaner, auth helpers, tenant CRUD.

### 4.8 Token Estimation Inaccurate

- **Files:** Multiple AI action files
- **Issue:** Uses `text.length / 4` for token estimation. Inaccurate for non-ASCII, code, and structured data. Analytics/billing data is systematically wrong.
- **Fix:** Use `tiktoken` or provider-specific tokenizer, or at minimum note the estimates are approximate in the UI.
