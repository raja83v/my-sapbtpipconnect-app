Context
CPI Connect recently migrated from SaaS (Convex + Clerk + Stripe) to self-hosted (PostgreSQL + Custom JWT + Prisma). The custom JWT auth system works but lacks features like OAuth, magic links, and password reset. The user has installed Supabase Docker locally (Studio: http://127.0.0.1:54323, PostgreSQL: port 54322, API: port 54321) and updated DATABASE_URL. The landing page still has SaaS-era pricing/trials messaging, and the auth pages are simple centered cards. This plan addresses all three issues.
Key constraint: getCurrentUser() in lib/auth-helpers.ts must maintain the exact same return type (CurrentUser) and function signatures so all 38+ server action files need zero changes.
